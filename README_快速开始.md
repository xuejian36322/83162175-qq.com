# 🚀 最简单的访问方式（无需配置）

由于扣子空间的云电脑有安全限制，无法直接外部访问，我为您提供以下方案：

---

## ⭐ 方案 1：使用免费托管（推荐，5分钟完成）

**适合人群**：不会配置服务器，只需要快速使用系统

### 步骤：

1. **将代码上传到 GitHub**
   - 如果您没有 GitHub 账号，先注册一个：https://github.com/
   - 创建一个新仓库
   - 上传项目文件

2. **使用 Vercel 免费托管**
   - 访问：https://vercel.com/
   - 用 GitHub 账号登录
   - 点击"New Project"
   - 选择您的仓库
   - 点击"Deploy"
   - **完成！** 自动获得一个 .vercel.app 域名

**费用**：完全免费，支持 HTTPS

---

## ⭐ 方案 2：使用 Netlify 免费托管（推荐）

### 步骤：

1. **推送到 GitHub**（同上）

2. **部署到 Netlify**
   - 访问：https://app.netlify.com/
   - 用 GitHub 账号登录
   - 点击"Add new site" → "Import an existing project"
   - 选择您的仓库
   - 点击"Deploy site"
   - **完成！** 自动获得域名

**费用**：完全免费，支持 HTTPS

---

## ⭐ 方案 3：使用阿里云 OSS（需要账号）

### 步骤：

1. **注册阿里云账号**（如果已有可跳过）
   - 访问：https://www.aliyun.com/

2. **开通 OSS 服务**
   - 搜索"对象存储 OSS"
   - 创建 Bucket（存储空间）
   - 读写权限设置为"公共读"

3. **上传文件**
   - 点击"文件管理"
   - 上传 `dist-web` 目录下的所有文件
   - 访问 OSS 提供的域名

**费用**：存储和流量费用极低（每月几块钱）

## 🔧 配置后端连接

前端部署后，还需要配置后端 API 地址：

1. **在代码中找到 `.env.local` 文件**
2. **修改 PROJECT_DOMAIN 为您的后端地址**
3. **重新构建前端**

如果使用免费托管（Vercel/Netlify）：
- 在项目设置中添加环境变量：`PROJECT_DOMAIN=http://your-backend-server`
